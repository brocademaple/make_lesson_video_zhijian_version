## 第一阶段交付了什么

- 创建分镜时可以选择逐镜配音。文字、图片准备好后即可开始，无需先找一条录好的整段声音。
- 每个镜头的旁白旁边有声音、语速、生成和试听控件。生成按钮会先保存当前编辑内容。
- 可以只重做当前镜头，或补齐所有未配音、旁白已修改的镜头；已有匹配配音不会被批量重做。
- 新声音生成成功后，根据真实音频长度更新镜头时长，按画面帧向上取整，避免尾音被切掉。
- 修改旁白会标记旧声音过期。配音没更新、音频文件丢失或镜头短于配音时，导出会提示先处理。
- 每次成功生成都保留版本。恢复版本会同时恢复旁白、声音和镜头时长。
- 原整段旁白文件保留。生成逐镜配音会切换成片的声音来源，其余有旁白的镜头需要补齐声音。
- 配音服务失败时保留已有声音；生成期间旁白被修改时，旧文本生成的声音不会覆盖新稿。

默认使用需要联网的 Edge 中文配音，有晓晓、云希、晓伊三个声音。已配置的 MiniMax 可选，按其服务计费，本轮没有进行付费服务的真实调用。

## 怎么运行和复验

macOS 双击桌面的 `启动-any2video.command`，打开 `第一阶段验收 · 逐镜配音`。选一个镜头，修改旁白并点“重做这一段”；试听后，可从版本菜单恢复。点击“生成成片”即可使用当前逐镜配音导出。

在仓库根目录运行：

```bash
.venv/bin/python -m pytest -q
node --check ppt_course_deal/static/v2-app.js
cd ppt_course_renderer
npm run lint
cd ..
.venv/bin/python scripts/verify_stage1_speech.py
```

真实验收脚本会联网生成中文声音、创建独立项目、导出 MP4 并比对每段声音；需要已安装 FFmpeg 和渲染器依赖。复验已有验收项目的成片声音可运行：

```bash
.venv/bin/python scripts/verify_stage1_speech.py 03a26ed3-7469-4c71-bc07-ac780510c3b5
```

本轮关键假设：先完成个人本地创作流程；默认联网配音；保留原素材和成功生成的历史版本；按阶段补充能力，暂不决定平台化或团队协作方向。
