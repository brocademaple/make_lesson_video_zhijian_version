## 一、课件处理与工作台：`ppt_course_deal`（`ppt-course-mvp` 包）

面向：将文字偏多的 `.pptx` 转为更偏「录课稿」的版式；提供 **命令行** 与 **本机 Web** 两种使用方式。

### 1.1 命令行

| 能力 | 说明 |
|------|------|
| `ppt-course transform` | 输入一份 `.pptx`，输出同目录下 `原文件名_course.pptx`（可用 `-o` 指定输出路径） |
| `ppt-course transform --plan-json` | 可选：将规划结果写出为 JSON 文件，便于排错或对接外部流程 |
| `ppt-course serve` | 启动 FastAPI + 静态前端（默认 `127.0.0.1:8765`，支持 `--host`、`--port`）；**默认开启 `--reload`**（代码变更自动重载）；线上常驻可加 **`--no-reload`** |
| `ppt-course --version` | 打印包版本号 |
| `ppt-course remotion-input-props` | 对已存 **`task_id`**：读取 **`ppt_course_data/tasks/<id>/previews/`** 与 **`audio_workspace/task/<id>/`**（`meta.json` 的 **`segment_duration_sec`**；缺失时用 **tinytag** 探测 mp3），写出 Remotion **`input-props.json`**（路径相对仓库根，含 **`audioRelatives`** + **`audioSegmentDurationInFrames`** 时 **`durationInFrames`** 为各段 **`ceil(秒×fps)`** 之和）；选项 **`-o`** **必选**，另有 **`--fps`**、**`--max-slides`**、**`--no-audio-frames`**、**`-w`/`--workspace-root`** |

入口：`python -m ppt_course_deal` 与 `ppt-course` 等价。

### 1.2 核心流水线（与 CLI / Web 共用）

| 环节 | 已实现行为 |
|------|------------|
| 读取 | 使用 `python-pptx` 打开 `.pptx`，逐页遍历形状（含组合图形内的文本） |
| 结构化抽取 | **启发式**：按关键词与规则将文本归为规则 / 案例 / 处罚 / 互动 / 小结 / 叙述等类型（见 `BlockKind`），非 LLM |
| 页面规划 | 按固定区块顺序聚合，超长内容按字数拆成「续页」 |
| 生成新版式 | 空白版式 + 标题区 + 分区正文文本框；可为备注页写入原始页摘录（便于口播参考） |
| 输出 | 写入新的 `.pptx` 文件 |

### 1.3 Web 服务（`ppt_course_deal/web/app.py`）

依赖：`FastAPI`、`uvicorn`、`python-multipart`、**`tinytag`**（音频时长探测；随根目录 `pyproject.toml` 安装）。

#### HTTP 接口

| 路径 | 方法 | 说明 |
|------|------|------|
| `/` | GET | 返回单页工作台前端（`static/index.html`） |
| `/assets/*` | GET | 静态资源（CSS / JS，及 MiniMax 普通话 **`voice_id`** 对照表 `minimax-mandarin-voices.json`） |
| `/api/health` | GET | 健康检查：``status``、``max_upload_mb``；另含 ``preview_render``（``ready``、``libreoffice`` / ``pdftoppm`` 是否探测到、可选路径、``install_hint_zh`` 安装提示） |
| `/api/parse` | POST | `multipart` 上传 `.pptx`，返回 JSON：文件名、页数、每页文本结构（标题、全文、`text_blocks`、备注、版式名、形状内图片数/表格数等）；可选生成预览会话；成功时在服务端**持久化**本次解析（见下），响应含可选字段 `task_id` |
| `/api/tasks` | GET | 已持久化解析任务的**摘要列表**（文件名、页数、创建时间、是否有预览图等） |
| `/api/tasks/{task_id}` | GET | 指定任务的完整解析 JSON（结构与解析接口正文一致，含 `slides` 全文） |
| `/api/tasks/{task_id}/preview/{slide_index}` | GET | 该任务已保存的第 `slide_index` 页 **整页 PNG**；优先 `previews/slide-NNNN/full.png`，否则回退到扁平 `previews/slide-NNNN.png`（旧任务） |
| `/api/tasks/{task_id}/slide/{slide_index}/full` | GET | 与上一行同源整页图（显式「按页目录」语义） |
| `/api/tasks/{task_id}/slide/{slide_index}/shapes` | GET | JSON：该页已导出的 **图片形状** 文件列表（`previews/slide-NNNN/shapes/shape-*.ext`） |
| `/api/tasks/{task_id}/slide/{slide_index}/shape/{shape_index}` | GET | 按序号（从 0 起）返回该页第 `shape_index` 张**内嵌图**（与 `/shapes` 列表顺序一致） |
| `/api/tasks/{task_id}` | DELETE | 删除该任务的本地目录（不可恢复） |
| `/api/preview/{session_id}/{slide_index}` | GET | 若预览会话存在且索引合法，返回对应页的 **PNG**（`image/png`） |
| `/api/transform` | POST | 上传 `.pptx`，返回课程化后的 **完整 `.pptx` 二进制**；响应头含 `X-Source-Slides`、`X-Output-Slides` |
| `/docs` | GET | FastAPI 自动生成的 OpenAPI 文档页面 |
| `/api/settings/external` | GET / PUT | 读取或保存本机 **外部 API** 配置（**`minimax`**、**`transcript_rewrite`（口播稿优化）**、**`agent`**；**`GET`** 另返回 **`transcript_rewrite_defaults.extra_instructions`**（默认 **空**：通用规范见 **`minimax_skill.md`**；非空时并入改写 **user** 内「课程追加规则」，不经长 **system**）；**`GET` 对 MiniMax / 口播稿优化的 `api_key` 返回明文**供工作台回显编辑，仅限同源本机勿暴露公网；**`PUT`** 可更新各项；**`api_key` 传空字符串表示清除已保存密钥**） |
| `/api/settings/external/minimax/test` | POST | MiniMax 语音合成**连通测试**（JSON：`minimax` 可选；与磁盘 **`merge_minimax_update`**；**`persist` 默认 true**：携带 `minimax` 且测试**成功后**将合并结果写入 **`config/external_apis.json`**；每次调用在 **`minimax_connect_tests/`** 落盘脱敏记录，响应含 **`archive_path`**；无请求体则仅用已保存配置、不写盘、仍生成记录） |
| `/api/settings/external/transcript-rewrite/test` | POST | 口播稿优化 **OpenAI 兼容**连通测试（JSON：`transcript_rewrite` 可选，与磁盘 **`merge_transcript_rewrite_update`** 合并后请求经 **`resolve_chat_completions_url`** 归一化的 **`…/v1/chat/completions`**）；未写入磁盘 |
| `/api/transcript/rewrite` | POST | JSON：`text`（≤9999 字符）；可选 **`transcript_rewrite`**（与磁盘 **`merge_transcript_rewrite_update`** 合并）。**user** 含 **`minimax_skill.md`** 全文 + 可选 **`【课程追加规则】`** + **`【待优化原文】`**；**system** 仅为 **`REWRITE_MINIMAL_SYSTEM`**（极短占位）。清理：**`sanitize_for_minimax_t2a`**；返回 **`rewritten_text`**、**`sanitize_warnings`** |
| `/api/audio/workspace` | GET | 查询当前任务或会话的**逐字稿**（扁平 `transcripts` + **多段** `transcript_segments`）、`generated_files`（键为 `{slide_index}-{segment_index}`，兼容旧版仅 `{slide_index}`）、**`segment_duration_sec`**（各段音频时长秒）、**`slide_duration_sec`**（每页各段时长之和，无记录时为 `null`，与数组下标对齐）等（`task_id` 或 `session_id` + 页数相关参数） |
| `/api/audio/workspace` | PUT | 保存多页逐字稿；请求体可含 **`transcript_segments`**（每页多段字符串数组）；缺省时由扁平 `transcripts` 推导为每页单段 |
| `/api/audio/workspace/generate` | POST | 按指定 **`slide_index`** 与 **`segment_index`**（默认 `0`）的一段逐字稿调用 MiniMax **T2A**；服务端默认 **`output_format`=`url`**，下载音频字节写入 **`audio_workspace/.../slide-NNNN/`**（见 **「1.4」** 小节音频工作台表）；写盘后用 **tinytag** 探测 **`duration_sec`** 并写入 **`meta.json`**；响应含本段 **`duration_sec`**、各页合计 **`slide_duration_sec`**（便于 Remotion：`durationInFrames ≈ ceil(秒 × fps)`）；请求体可含 `minimax_overrides`（白名单字段含 **`pronunciation_dict`**、**`subtitle_enable`** 等，**不得**传 `api_key` / `api_base`）；MiniMax **`audio_setting.channel=1`**（单声道） |
| `/api/audio/workspace/file` | GET | 流式返回已生成的音频文件；查询参数 **`segment_index`**（默认 `0`）定位多段之一；兼容旧版根目录扁平命名 **`slide-NNNN-seg-…`** 与 **`slide-NNNN.{ext}`** |
| `/api/audio/workspace/import-transcript/preview` | POST | JSON：`task_id`、`text`。解析整稿（`### 第 N 页`，第 1 页对应幻灯片 index `0`），返回 **`warnings`**、**`conflicts`**（已有逐字稿非空且与导入不一致的页）、**`filled_slides`** 等（不写盘） |
| `/api/audio/workspace/import-transcript/apply` | POST | JSON：`task_id`、`text`；若预览存在 **`conflicts`**，须带 **`resolutions`**（键为 **`slide_index` 字符串**，值为 **`import`** 或 **`keep`**）。写入 **`audio_workspace/task/<task_id>/meta.json`** 的 **`transcript_segments`** |

上传体积上限：**默认单文件 50MB**；环境变量 **`PPT_COURSE_MAX_UPLOAD_MB`** 可提高到至多 **4096**（MB）。`/api/parse` 与 `/api/transform` 使用同一上限；服务端按 **分块**读入并在超过上限时拒绝，避免单次超大 `read()`。极大文件仍会整份载入内存做解析 / 转换，请保证机器内存与磁盘。若经 **Nginx / Caddy** 等反代，需同步放宽请求体大小（如 `client_max_body_size`）。命令行 **`ppt-course transform`** 无此 Web 上限。

| 对外 API 文档 | 顶栏 **API** 打开新标签 **Swagger UI**（``GET /docs``）；机器可读 **OpenAPI JSON** 为 ``GET /openapi.json``，供 **ppt_course_rebuilder** 等生成客户端或对照接口。与顶栏 **外部 API 配置**（本机 MiniMax 密钥）不是同一功能 |
| 多段逐字稿与 TTS | **音频工作台**保留紧凑入口：**保存逐字稿**、**打开本页逐字稿与音频**（弹窗内按页维护 **多段**口播）、**进入音频生成设置**。逐段 **「口播稿优化」**打开对比弹窗（左原文 / 右改写稿），**「开始改写」**请求 `POST /api/transcript/rewrite`（改写中按钮 **loading + 禁用**）；确认后 **「采用改写稿」**写回本段；可选勾选 **存入本段「口播版本库」**（浏览器 **`localStorage`**，按任务/页/段键控，最多约 **25** 条）；**📚** 打开 **「口播版本库」**可选用历史改写稿。逐段点「生成」后弹出 **「确认生成本段音频」**，说明文案经标题旁 **说明图标** 打开 `#help-dialog`；确认后 **「开始生成」** 才请求 `POST /api/audio/workspace/generate`（仅当前段）。「本页逐字稿与音频」与 **「音频生成参数」**弹窗的长说明均改为标题旁 **ⓘ**，完整用法与 **API Key 须在顶栏「外部 API 配置」填写**等说明写在 `#help-dialog`。支持保存到服务端、逐段试听/下载（试听 URL 仍为 **`segment_index`** 定位，与磁盘子目录无关）；已生成段展示 **时长（秒）**，页标题行展示 **本页音频合计秒数**（与 **`slide_duration_sec`** 一致，便于换算 Remotion **`durationInFrames`**）。主预览区标题行 **喇叭**仅打开 **本页已生成**各段 MP3 的 **试听 / 下载**（与完整逐字稿弹窗分 mode：**`audioSegmentsDialogListenOnly`**；无已生成段时提示走「打开本页逐字稿与音频」）；**`.preview-toolbar`** 提高 **`z-index`** 避免滚动层挡点击。逐字稿编辑、口播优化与 **生成** 仅通过 **「打开本页逐字稿与音频」**。切换幻灯片时若逐字稿弹窗保持打开，列表会随当前页刷新。默认 MiniMax **`output_format`=`url`**（可在「外部 API 配置」或「进入音频生成设置」中改为 `hex` 等）；服务端将返回的音频写入 **`audio_workspace/.../slide-NNNN/seg-{段}-Slide{页码}_{文案首部约十字}.{ext}`**（文案摘要规则见 **`safe_stub`**；非法文件名字符已剔除）；**按页分子目录**便于与 **`previews/slide-NNNN`** 对齐、对接 Remotion |
| 外部 API 与合成 | 顶栏 **「外部 API 配置」**含三个 Tab：**MiniMax 语音**、**口播稿优化 API**、**智能体（预留）**。**口播稿优化**（**`transcript_rewrite`**）：OpenAI 兼容 **`/v1/chat/completions`**（**`api_base`** 仅填网关根域名时服务端 **`resolve_chat_completions_url`** 自动补 **`/v1`**；已以 **`/v1`** 结尾或已填完整 **`…/v1/chat/completions`** 亦兼容；请求体显式 **`stream: false`**）；**API Key** 为**单边框** + **眼睛**显隐（**无** MiniMax 那种左侧 **Bearer** 固定文案；服务端仍按 OpenAI 惯例发送 **`Authorization: Bearer …`**）；**`model`** 为 **`<select>`**（**已筛掉**向量嵌入 / 文生图 / 视频等不适配口播改写的模型，按性价比大致排序；未列出的模型可改 **`external_apis.json`** 后由 **`ensureSelectHasOption`** 回显）；**通用 MiniMax 口播改写规范**由包内 **`ppt_course_deal/transcript_rewrite/minimax_skill.md`** 在 **`POST /api/transcript/rewrite`** 时注入 **user** 消息（不经 **追加规则** 文本框）；**追加规则**仅作可选 **课程专属补充**，保存后并入改写 **user** 内「课程追加规则」（默认空）；**`load_raw()`** 可将曾落盘的旧版短模板或「完整 V2 默认追加规则」迁移为清空，避免与内置 skill 重复。其余同前：MiniMax 默认 **`model`=`speech-2.8-turbo`** 等；**`POST .../transcript-rewrite/test`**；**「进入音频生成设置」**与 **`minimax_overrides`** |

#### 整页 PNG 预览（可选能力）

- **条件**：运行 Web 服务的机器已安装并可调用 **LibreOffice（`soffice`）** 与 **Poppler（`pdftoppm`）**。  
- **过程**：`PPTX → PDF（LibreOffice）→ 逐页 PNG（pdftoppm）`，文件落在临时目录；通过 `session_id` 绑定会话。  
- **会话**：内存中登记预览会话，临时目录超出数量上限（约 30 个会话规模）时淘汰较早会话并删除目录。  
- **限制**：刷新浏览器后需重新上传；**不是**公网 CDN，仅为同源临时 URL。

## 文档修订记录

### 编排规则（请先读）

- **日期是大分类**：每一档独立的日历日以三级标题 **`### YYYY-MM-DD（中文日期）`** 表示；**多个日期之间**：较新的日期写在**上面**，较早的日期写在**下面**。  
- **同一天内可能有多轮迭代**：在同一日期标题下，用四级标题 **`#### 迭代 n`** 区分（`n` 可取 1、2、3…，**数值越大表示当日越晚、越新**）；**同一天内**，较新的迭代写在**上面**，较早的迭代依次往下（即从**上到下 = 从新到旧**）。  
- 若当日最新一轮需要醒目，可在标题后缀 **`（本日最新）`**。
