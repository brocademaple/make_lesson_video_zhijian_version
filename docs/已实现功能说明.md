## 一、课件处理与工作台：`ppt_course_deal`（`ppt-course-mvp` 包）

面向：将文字偏多的 `.pptx` 转为更偏「录课稿」的版式；提供 **命令行** 与 **本机 Web** 两种使用方式。

### 1.1 命令行

| 能力 | 说明 |
|------|------|
| `ppt-course transform` | 输入一份 `.pptx`，输出同目录下 `原文件名_course.pptx`（可用 `-o` 指定输出路径） |
| `ppt-course transform --plan-json` | 可选：将规划结果写出为 JSON 文件，便于排错或对接外部流程 |
| `ppt-course serve` | 启动 FastAPI + 静态前端（默认 `127.0.0.1:8765`，支持 `--host`、`--port`、`--reload`） |
| `ppt-course --version` | 打印包版本号 |

入口：`python -m ppt_course_deal` 与 `ppt-course` 等价。

### 1.2 核心流水线（与 CLI / Web 共用）

| 环节 | 已实现行为 |
|------|------------|
| 读取 | 使用 `python-pptx` 打开 `.pptx`，逐页遍历形状（含组合图形内的文本） |
| 结构化抽取 | **启发式**：按关键词与规则将文本归为规则 / 案例 / 处罚 / 互动 / 小结 / 叙述等类型（见 `BlockKind`），非 LLM |
| 页面规划 | 按固定区块顺序聚合，超长内容按字数拆成「续页」 |
| 生成新版式 | 空白版式 + 标题区 + 分区正文文本框；可为备注页写入原始页摘录（便于口播参考） |
| 输出 | 写入新的 `.pptx` 文件 |

### 1.3 Web 服务（`ppt_course_deal/web/app.py`）

依赖：`FastAPI`、`uvicorn`、`python-multipart`（随根目录 `pyproject.toml` 安装）。

#### HTTP 接口

| 路径 | 方法 | 说明 |
|------|------|------|
| `/` | GET | 返回单页工作台前端（`static/index.html`） |
| `/assets/*` | GET | 静态资源（CSS / JS） |
| `/api/health` | GET | 健康检查：``status``、``max_upload_mb``；另含 ``preview_render``（``ready``、``libreoffice`` / ``pdftoppm`` 是否探测到、可选路径、``install_hint_zh`` 安装提示） |
| `/api/parse` | POST | `multipart` 上传 `.pptx`，返回 JSON：文件名、页数、每页文本结构（标题、全文、`text_blocks`、备注、版式名、形状内图片数/表格数等）；可选生成预览会话；成功时在服务端**持久化**本次解析（见下），响应含可选字段 `task_id` |
| `/api/tasks` | GET | 已持久化解析任务的**摘要列表**（文件名、页数、创建时间、是否有预览图等） |
| `/api/tasks/{task_id}` | GET | 指定任务的完整解析 JSON（结构与解析接口正文一致，含 `slides` 全文） |
| `/api/tasks/{task_id}/preview/{slide_index}` | GET | 该任务已保存的第 `slide_index` 页 **整页 PNG**；优先 `previews/slide-NNNN/full.png`，否则回退到扁平 `previews/slide-NNNN.png`（旧任务） |
| `/api/tasks/{task_id}/slide/{slide_index}/full` | GET | 与上一行同源整页图（显式「按页目录」语义） |
| `/api/tasks/{task_id}/slide/{slide_index}/shapes` | GET | JSON：该页已导出的 **图片形状** 文件列表（`previews/slide-NNNN/shapes/shape-*.ext`） |
| `/api/tasks/{task_id}/slide/{slide_index}/shape/{shape_index}` | GET | 按序号（从 0 起）返回该页第 `shape_index` 张**内嵌图**（与 `/shapes` 列表顺序一致） |
| `/api/tasks/{task_id}` | DELETE | 删除该任务的本地目录（不可恢复） |
| `/api/preview/{session_id}/{slide_index}` | GET | 若预览会话存在且索引合法，返回对应页的 **PNG**（`image/png`） |
| `/api/transform` | POST | 上传 `.pptx`，返回课程化后的 **完整 `.pptx` 二进制**；响应头含 `X-Source-Slides`、`X-Output-Slides` |
| `/docs` | GET | FastAPI 自动生成的 OpenAPI 文档页面 |
| `/api/settings/external` | GET / PUT | 读取或保存本机 **外部 API** 配置（MiniMax 公开展示字段 + 脱敏后的密钥状态；`PUT` 可更新模型、音色、密钥等；**不含**将密钥返回给浏览器） |
| `/api/settings/external/minimax/test` | POST | MiniMax 语音合成**连通测试**（服务端使用已保存密钥请求 T2A） |
| `/api/audio/workspace` | GET | 查询当前任务或会话的**逐字稿行数/文本**、已生成音频记录等（`task_id` 或 `session_id` + 页数相关参数） |
| `/api/audio/workspace` | PUT | 保存多页逐字稿文本 |
| `/api/audio/workspace/generate` | POST | 按当前页逐字稿调用 MiniMax **T2A** 生成本页音频；请求体可含 `minimax_overrides`（白名单内的模型、音色、语速等单次覆盖，**不得**传 `api_key` / `api_base`） |
| `/api/audio/workspace/file` | GET | 流式返回已生成的某页音频文件（音轨格式与配置中的 `audio_format` 一致） |

上传体积上限：**默认单文件 50MB**；环境变量 **`PPT_COURSE_MAX_UPLOAD_MB`** 可提高到至多 **4096**（MB）。`/api/parse` 与 `/api/transform` 使用同一上限；服务端按 **分块**读入并在超过上限时拒绝，避免单次超大 `read()`。极大文件仍会整份载入内存做解析 / 转换，请保证机器内存与磁盘。若经 **Nginx / Caddy** 等反代，需同步放宽请求体大小（如 `client_max_body_size`）。命令行 **`ppt-course transform`** 无此 Web 上限。

#### 浏览器端界面（`ppt_course_deal/static/`）

| 能力 | 说明 |
|------|------|
| 上传 | 选择或拖放 `.pptx`（主页约为 **35% : 65%** 两栏：**左侧为已存任务列表**、右侧为上传区） |
| 已存任务 | 主页左侧栏列出本机已持久化的解析记录（可滚动）；点击条目在**主界面**进入工作台（左侧切换为**幻灯片缩略图** + 右侧大图，接口 `/api/tasks/...`）；支持刷新列表、单项删除；删除当前正在查看的任务会退回上传页 |
| 解析后布局 | 工作台为约 **35% : 65%** 两栏：左侧缩略图栏高度随视口与顶栏**约束为顶栏以下剩余屏高**（`.app` 采用 flex 填满 `100dvh`）；**缩略图列表区域**使用 **`overflow-y: scroll` + `scrollbar-gutter: stable`**，滚动条轨道常显；右侧为当前页大图与说明；其下 **「当前页解析文本」**为可折叠面板（**默认展开**）；再下为**音频工作台** |
| 工作台任务抽屉 | 进入工作台后主界面**左侧边缘**显示 **›** 展开条；点击后从左侧滑出 **「已存任务」**列表（与首页、`GET /api/tasks` **同源**；**无**刷新/删除/重命名）。点击某任务与首页点击一致：**切换任务并重载**缩略图、大图、解析文本与音频工作台；**Esc** 或 **关闭** 或 **点击遮罩**收起 |
| 整页缩略图 / 大图 | **上传会话**：缩略图与大图使用 `/api/preview/{session_id}/{index}`。**已存任务**：使用 `/api/tasks/{task_id}/preview/{index}`。未生成 PNG 时列表为数字占位，右侧仅文本 |
| 生成课程化 | 使用「生成课程化 PPTX」按钮，对**当前已上传文件**再次请求并下载（与命令行 `transform` 同一套流水线）；**仅从已存任务打开、未重新上传文件时**该按钮不可用 |
| 返回首页 | 工作台左侧栏「返回首页」按钮回到上传区，可换另一份 `.pptx` 重新解析 |
| 外部 API 与合成 | 顶栏可打开 **「外部 API 配置」**保存 MiniMax 密钥与**默认**合成参数；**音频工作台**内 **「进入音频生成设置」**打开弹窗，可调整 **T2A** 相关参数（模型、音色、`language_boost`、格式、采样率、码率、语速/音量/音高/情绪、`stream`、可选 `group_id`）；**保存合成参数**将偏好写入浏览器 `localStorage`，**生成本页音频**时在请求体附带 `minimax_overrides`；**恢复服务端默认**清除本地覆盖并以服务端 GET 配置回填表单；点击 **「生成本页音频」**先弹出确认框，展示合并后的合成参数预览与本页逐字稿全文，在框内点击 **「开始生成」**后才发起合成请求 |

#### 整页 PNG 预览（可选能力）

- **条件**：运行 Web 服务的机器已安装并可调用 **LibreOffice（`soffice`）** 与 **Poppler（`pdftoppm`）**。  
- **过程**：`PPTX → PDF（LibreOffice）→ 逐页 PNG（pdftoppm）`，文件落在临时目录；通过 `session_id` 绑定会话。  
- **会话**：内存中登记预览会话，临时目录超出数量上限（约 30 个会话规模）时淘汰较早会话并删除目录。  
- **限制**：刷新浏览器后需重新上传；**不是**公网 CDN，仅为同源临时 URL。

### 1.4 解析结果本地持久化（可选目录）

| 项 | 说明 |
|----|------|
| 触发时机 | 每次 `/api/parse` **解析成功**（含仅有文本、无 PNG 的情形）后写入磁盘 |
| 默认目录 | 仓库根目录 **`ppt_course_data/tasks/{uuid}/`**（内含 `meta.json`（解析全文 + 可选 `shape_image_manifest`）、`source.pptx`、`previews/`：扁平 `slide-NNNN.png` 与**按页目录** `slide-NNNN/full.png`、`slide-NNNN/shapes/shape-XXXX.ext`（**python-pptx** 导出的 PICTURE 内嵌图，不含图表/SmartArt 等））；旧版曾为 `ppt_course/user_data/` 或 `ppt_course_deal/user_data/`，若仍在使用环境变量 `PPT_COURSE_DATA` 则以该路径为准 |
| 环境变量 | `PPT_COURSE_DATA`：指定数据根目录（绝对或相对路径均可），任务位于其下 `tasks/` |
| 容量 | 任务数超过 **200** 条时自动删除**最旧**目录 |

## 文档修订记录

### 编排规则（请先读）

- **日期是大分类**：每一档独立的日历日以三级标题 **`### YYYY-MM-DD（中文日期）`** 表示；**多个日期之间**：较新的日期写在**上面**，较早的日期写在**下面**。  
- **同一天内可能有多轮迭代**：在同一日期标题下，用四级标题 **`#### 迭代 n`** 区分（`n` 可取 1、2、3…，**数值越大表示当日越晚、越新**）；**同一天内**，较新的迭代写在**上面**，较早的迭代依次往下（即从**上到下 = 从新到旧**）。  
- 若当日最新一轮需要醒目，可在标题后缀 **`（本日最新）`**。
