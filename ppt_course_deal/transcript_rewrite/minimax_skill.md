# MiniMax T2A 口播改写规范（内置技能）

在向大模型请求「口播稿优化」时，本文件完整置于 **user** 消息；**system** 仅为极简角色说明。合法插入语以 **[MiniMax T2A 支持的插入语]** 列表为准（须与仓库 `minimax_t2a_allowlist.json` 一致；若有出入以 JSON + 下游 sanitize 为准）。

【场景与语气】

面向在线课程录播：普通话自然、有节奏感，像在教室里对学生讲解，但避免机械念稿。在忠于知识点的前提下，让听众**愿意听下去**：句式有变化、重点有着落，可适当用口语衔接（如「那么」「接下来」「我们看一下」），不要堆砌口头禅；禁止编造其它英文括号标签或自造 (中文) 效果。

【MiniMax T2A 支持的插入语（仅允许下列英文标签，须小写、带括号，与官方 speech-2.8 等模型说明一致）】

下列均为合法 token，可按语境选用，用于**气息衔接、情绪层次、停顿感**，减轻「读稿机」感：

- **允许相邻叠用**（例如一句内 `(sighs)(breath)` 或换气前后连续两个标签），只要服务于语气自然、不喧宾夺主即可。
- **不要**为了炫技整段密集堆砌；也**不要**每一句都机械地塞标签——用在转折点、情绪落差或需要「喘一口气」的位置更有说服力。

- (laughs)（笑声）
- (chuckle)（轻笑）
- (coughs)（咳嗽）
- (clear-throat)（清嗓子）
- (groans)（呻吟）
- (breath)（正常换气）
- (pant)（喘气）
- (inhale)（吸气）
- (exhale)（呼气）
- (gasps)（倒吸气）
- (sniffs)（吸鼻子）
- (sighs)（叹气）
- (snorts)（喷鼻息）
- (burps)（打嗝）
- (lip-smacking)（咂嘴）
- (humming)（哼唱）
- (hissing)（嘶嘶声）
- (emm)（嗯 / 迟疑）
- (sneezes)（喷嚏）

【停顿标记】

使用 <#x#> 表示停顿 x 秒，x 在 [0.01, 99.99]，最多两位小数；夹在可朗读文本之间。停顿用于「留给听众消化」或「换口气」，避免无意义地连续多个 <#…#> 把节奏切碎。

【与合成参数 emotion 区分】

voice_setting.emotion（happy/calm 等）由用户在 MiniMax 合成界面单独配置；**不要把上述英文情绪单词当作口播正文插入**。情绪层次优先用内容、标点、换行与本节白名单标签表达。

【内容与节奏】

保留知识点、术语与数字，不编造事实。长句拆分，逗号/句号/问号换气；段落换行。书面语可口语化，但不改变专业含义。可适当制造**轻度的讲解起伏**（提问、小结、预告下一句），减轻单调感。

【篇幅】

改写长度一般不超过原文约 1.15 倍；不要为了凑字数重复啰嗦或疯狂堆标签。
