仓库怎么拆

remotion

核心时间线：Composition、Sequence、useCurrentFrame、interpolate。

@remotion/studio

本地预览、拖动时间轴、调镜头节奏。

@remotion/renderer

服务端或脚本里把 Composition 渲成 MP4 / 音频。

@remotion/media

视频、音频素材轨道；裁剪、变速、音量曲线。

@remotion/transitions

镜头之间做淡入、滑动、擦除；Overlay 做光效层。

any2video renderer

读取 render_tasks 下的入参，生成企业培训视频。

02

制作规范

先定 Composition

id、fps、width、height、durationInFrames 是成片契约。

所有动画按帧算

useCurrentFrame + interpolate，比 CSS 动画更稳定。

镜头用 Sequence 装

from 控制开始帧，durationInFrames 控制挂载长度。

素材走 staticFile

public 暴露图片、音频、视频；路径由入参统一生成。

03

Agent Skill 快照

什么时候必须加载

只要要写、审、改 Remotion 代码，就先加载 Remotion Skill，再决定 Composition、素材路径、时间线和渲染校验。

关键禁区

不要用 CSS animation 或 Tailwind 动画类做视频动效；渲染帧不稳定。动效必须由 frame、interpolate、Easing 驱动。

素材约束

图片、音频、视频进入 public 或可被 public 暴露的目录；React 里用 staticFile、Img、Audio、Video 引用。

时间线约束

Sequence 控制延迟和持续帧数；Series 负责顺序播放；字幕、口播和画面层必须共用 fps 口径。

本项目给 Agent 的编排 Brief 
目标：把素材、脚本、音频和视效组件编排成个人创作 MP4。
输入：video_project.json、render_plan.json、input-props.json、screenshots/、audio_workspace/。
输出：Remotion React 组件 + 可渲染 MP4。
必须做：
- 用 Composition 定义 fps / 画幅 / 动态 durationInFrames。
- 用 Sequence / Series 分镜；字幕和音频按帧对齐。
- 用 useCurrentFrame + interpolate 做镜头运动、文字入场、局部变焦和标注。
- 按 templatePackage 切换产品体验、知识讲解、作品复盘、工具教程等画面策略。
- 渲染前至少做 still/frame sanity check；发现遮挡、溢出、空白帧要回改。
常用 rules 索引
  • sequencing用 Sequence、Series、offset 拆时间线。
  • timing用 interpolate + Bézier，把“什么时候动”和“动到哪里”分开。
  • transitions需要镜头转场时再接 @remotion/transitions；Transition 会缩短总时长。
  • images / audio / videos控制素材尺寸、裁剪、音量、变速、trimBefore / trimAfter。
  • measuring-text标题、字幕、卡片文字可能溢出时必须测量或降级布局。

04

剪辑和拼接

  • 口播时长决定每页帧数：Math.ceil(seconds * fps)。
  • 多段音频按顺序放入 Series，字幕按 start_sec / end_sec 对齐。
  • 裁掉素材头尾：trimBefore / trimAfter。
  • 转场用 TransitionSeries；Transition 会让两段重叠，Overlay 不改总时长。
  • 创作视频保留素材依据：截图、局部放大、重点标注都来自 video_project / render_plan。
<TransitionSeries>
  {slides.map((slide) => (
    <TransitionSeries.Sequence durationInFrames={slide.durationInFrames}>
      <CourseScene slide={slide} />
    </TransitionSeries.Sequence>
  ))}
</TransitionSeries>
