Pipeline

DL → Rebuilder → Remotion

每一步都落成可检查的 JSON 或媒体文件，便于人工审核、自动测试和稳定复现。

01

Deal / DL

上传 PPT，抽取文本、备注、shape 图片并渲染逐页预览图，形成 raw material manifest。

02

Rebuilder

归一化素材，给页面和风险内容打标签，生成带证据链的 director manifest。

03

Audio

逐页逐段生成口播音频；MiniMax 不可用时自动切换到 edge-tts 保证链路不断。

04

Remotion

将审核后的导演脚本转为 render plan / input-props，由 React 模板确定性渲染 MP4。
