把培训课件做成可审核的视频生产线

智课影擎面向企业内训、质检规范和流程教学。上传 PPT 后，工作台会沉淀素材、脚本、口播和渲染入参，让每一步都能检查、重跑和替换。

产品流程和工程流程分开看

用户侧

上传课件，选择视频方向，审核脚本与音频

页面聚焦“我要把这份 PPT 变成什么类型的视频”，让审核动作和成片结果成为主线。

系统侧

生成可追溯产物，再交给渲染器

Manifest、音频工作区和 Remotion props 是工程产物，适合放在流程详情、架构图和运行说明里。

项目里真正发生了什么

前端工作台负责上传、选择视频方向和审核产物；后端流水线负责生成 JSON 与媒体文件；Remotion 只接收确定的渲染入参。

本地运行

命令放在开发者区，不和产品流程抢层级。

.venv/bin/ppt-course course-material <task_id>
